Este projeto representa a segunda versão de uma API de e-commerce desenvolvida anteriormente, que foi meu primeiro projeto backend completo e que atualmente está em produção, com deploy público e acessível via link.

A versão anterior pode ser encontrada em:
👉 https://github.com/KaykMurphy/bytemarket

Esse primeiro projeto foi fundamental para o aprendizado prático e para ganhar experiência com um sistema real em funcionamento.
No entanto, por se tratar de uma aplicação já em produção e por conter decisões arquiteturais iniciais típicas de um projeto de aprendizado, optou-se pela criação de uma nova versão, permitindo aplicar desde o início uma arquitetura mais organizada, boas práticas e maior facilidade de manutenção e evolução.
